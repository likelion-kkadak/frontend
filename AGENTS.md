# Frontend changes

- Create a topic branch for frontend changes and submit them through a pull request.
- Push topic branches only; never push directly to the default branch.
- Merge only with explicit maintainer approval.
- Use Conventional Commit subjects such as `fix:`, `feat:`, and `docs:`.
- When checked out under GGADDAK, follow the parent AGENTS.md and run checks in its Herdr verify pane.
